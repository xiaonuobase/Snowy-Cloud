# 工具类使用指南

> 决策树：**Common* 工具 → Hutool → Spring/官方 API → 才自写**。完整索引见 `.claude/skills/common-toolkit`。
> 微服务版公共模块路径：`snowy-base/snowy-common/src/main/java/vip/xiaonuo/common/`（包名 `vip.xiaonuo.common`，web-app、biz-app、网关共用）。

## snowy-common 工具类（17 个）

| 工具类 | 一句话用途 |
|---|---|
| CommonCryptogramUtil | 国密：doSm2Encrypt/doSm2Decrypt/doHashValue（SM3）/doSm4CbcEncrypt/doSm4CbcDecrypt |
| CommonEmailUtil | 邮箱格式校验（isNotEmail/validEmail；发邮件走 DevEmailApi） |
| CommonDownloadUtil | 文件下载写流 |
| CommonAvatarUtil | 按姓名生成文字头像 |
| CommonOtpUtil | OTP 动态口令 |
| CommonSqlUtil | SQL 兼容（safeIn 拆分超长 IN、scopeIn 数据范围过滤） |
| CommonResponseUtil | 向 response 写 JSON（过滤器场景） |
| CommonServletUtil | Request/Response 获取 |
| CommonKeyUtil | 密钥混淆存储与 SM2/SM4 密钥生成 |
| CommonIpAddressUtil | IP 归属地（ip2region） |
| CommonUaUtil | 浏览器/系统解析 |
| CommonTraceIdUtil | 链路 traceId |
| CommonTimeFormatUtil | 友好时间展示（"x 分钟前"、秒转时分秒） |
| CommonNetWorkInfoUtil | 网速采集（监控） |
| CommonJoinPointUtil | AOP 参数获取 |
| CommonFilterExceptionUtil | 过滤器异常统一转发处理 |
| CommonThreadLocalUtil | ThreadLocal 键值存取（微服务版新增） |

## 禁止事项

1. ❌ 引入 commons-lang3 / guava 等（hutool 已覆盖）
2. ❌ 手写 MD5/SHA/AES（国密标准走 CommonCryptogramUtil）
3. ❌ 重复造轮子（自写前必须查本清单）
4. ❌ Controller 手写下载流（CommonDownloadUtil）
5. ❌ 业务代码拼 Redis key（CacheConstant + CommonCacheOperator）
6. ❌ `@FeignClient` 里硬编码服务名（用 FeignConstant）

## 自写工具的落位

- 仅本插件用 → `snowy-plugin/snowy-plugin-biz/snowy-plugin-biz-func/src/main/java/vip/xiaonuo/biz/core/util/`
- 全项目通用 → 提议下沉 `snowy-base/snowy-common/src/main/java/vip/xiaonuo/common/util/`（命名 Common{Xxx}Util）
