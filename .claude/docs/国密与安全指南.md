# 国密与安全指南

> Snowy 的定位就是"国密前后端分离平台"，软件层面满足等保测评。详细 API 见 `.claude/skills/crypto-sm` 与 `.claude/skills/security-auth`。

## 国密三层架构

| 层 | 算法 | 保护什么 | 实现 |
|---|---|---|---|
| 传输加密 | SM2（非对称） | 登录口令网络传输 | 前端 smCrypto.js 公钥加密 → 后端 CommonCryptogramUtil.doSm2Decrypt |
| 口令摘要 | SM3（哈希） | 口令存储 | CommonCryptogramUtil.doHashValue（口令规则校验在 sys 插件 SysPasswordUtil，只在 web-app 内），库中只有摘要 |
| 字段加密 | SM4-CBC（对称） | 手机号/证件号等落库 | CommonSm4CbcTypeHandler（MyBatis TypeHandler） |

密钥存放：**不在配置文件里**——SM2 私钥、SM4 key/IV 以异或混淆字节数组写在 `snowy-base/snowy-common` 的 `CommonCryptogramUtil` 中，SM2 公钥同时写在前端 `smCrypto.js`。生产环境必须用 `CommonKeyUtil` 生成自己的密钥替换，前后端公钥同步；snowy-common 被网关、web-app、biz-app 共用，换密钥后所有服务重新构建重启。**业务代码严禁另存密钥**。

## 敏感字段加密（新字段标准做法）

```java
@TableName(value = "BIZ_PATIENT", autoResultMap = true)      // ①
public class BizPatient extends CommonEntity {

    @TableField(typeHandler = CommonSm4CbcTypeHandler.class)  // ②
    @Schema(description = "手机号")
    private String phone;
}
```

查询限制（重要）：
- 密文 **like 永远查不到**——精确查先 doSm4CbcEncrypt 再 eq；模糊查用 SM3 摘要辅助列（如 PHONE_HASH）
- 参考实战：BizUser 的 phone/idCardNumber/emergencyPhone

## 口令处理规范

- 传输：SM2（前端加密，后端解密）——新业务口令类字段照抄登录链路
- 存储：SM3 摘要——**任何口令不得明文/可逆存储**
- 日志：不打口令与敏感字段明文

## 鉴权安全

1. **白名单最小化**：免登录接口必须逐条登记，且**两处都要登记**——网关 GatewayConfigure.NO_LOGIN_PATH_ARR（带 `/api/webapp`、`/api/bizapp` 前缀）+ 目标服务 GlobalConfigure.NO_LOGIN_PATH_ARR（不带前缀），改后重启网关与服务；禁止用通配符放开大范围
2. **越权防护**：编辑/删除接口校验数据归属（当前用户机构/本人）；关键操作加 @CommonNoRepeat
3. **SQL 注入**：QueryWrapper 一律 checkSqlInjection() + lambda 列名；动态排序字段过 CommonSortOrderEnum.validate + toUnderlineCase
4. **上传安全**：走 dev/file 标准接口（图片接口校验格式）；下载走 authDownload（鉴权）
5. **会话**：Sa-Token 30 天（timeout 2592000）；敏感系统建议配置缩短 + 单端登录（开关在各服务 Nacos 配置的 sa-token 段，web-app、biz-app、网关三份必须一致）。会话存 Redis 跨服务共享，三者 Redis 库号也必须一致
6. **两层鉴权**：网关 SaReactorFilter + 各服务 SaServletFilter 都会校验；直连服务端口（9101/9102）同样要登录，生产环境不要把服务端口直接暴露到公网，只开放网关
7. ⚠️ **现状提醒**：
   - 服务侧把 `/feign/**`（内部 Feign 接口）列为免登录，feign-provider 无 `@SaCheckPermission`，网关也未拦截 `/api/*/feign/**`，登录用户可能经网关直调内部接口（推导，未验证）——生产部署前评估在网关屏蔽该路径
   - 非超管经网关访问超管专属路径时，网关 NotRoleException 分支返回 500 而非 403（AuthExceptionUtil 在响应式环境取 Servlet 请求出错）

## 权限体系要点（防越权设计）

- 接口权限：@SaCheckPermission 值 = URL，权限来自角色资源授权的 apiUrl 集合——**新接口不授权 = 默认拒绝**（默认安全）
- 按钮权限：驼峰码只控制显示，**后端必须有自己的校验**（前端隐藏不是安全边界）
- 数据范围：敏感数据列表按 orgId 数据范围过滤（角色管理→数据授权）
